# Expense Tracker

A simple web app to record daily expenses, filter them by category, and see where the money goes. Data is saved in the browser using localStorage.

**Built with:** HTML, CSS, JavaScript, Chart.js

## Features
- [x] Add an expense (title, amount, category, date)
- [x] Delete an expense
- [x] Data persists after refresh (localStorage)
- [x] Total updates automatically
- [x] Filter by category
- [x] Spending-by-category chart
- [x] Input validation
- [x] Responsive layout

## How to run
Open `index.html` in your browser. No installation needed.
